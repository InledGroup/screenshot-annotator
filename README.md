# Screenshot Annotator  
If you have been used a Mac, you will miss the native editor which the Mac provides.  
This extension provides a complete editor for screenshots, auto-detecting the screenshots folder and providing a full-featured editor for annotations. 
With OCR included (for english only).  

## Capabilities
- Free draw  
- Shapes (circles and rectangles)  
- Text annotations
- Pixelate/censoring
- OCR (english only)
- Fast copy to clipboard
- Intuitive UI

## Installation  
We are working to publish this extension in GNOME Extensions.
